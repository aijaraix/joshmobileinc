ONE-TIME GOOGLE SETUP

Connect the business workspace

Josh authorizes the supplied Google Apps Script under his own account. It creates private storage and a private appointments calendar. The public website never requires a customer Google login.

  1. Open the setup instructions and install the supplied Google workspace files while signed in to the business account.
  2. Run the setup once and approve Google’s permissions. Deploy the script as a web app that runs as the owner.
  3. Add the script deployment URL and secret to this Vercel project’s encrypted settings. Then test a real submission and both administrator logins before enabling online intake.
